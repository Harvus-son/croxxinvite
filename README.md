# ✠ Croxxinvite — Medieval Invitation

Шуточный интерактивный сайт-приглашение в стилистике средневековой королевской грамоты.

## Что внутри

- интерактивное письмо с печатью;
- анимация открытия;
- пергамент и средневековая типографика;
- замок, туман и свеча;
- шуточное приглашение;
- кнопки «Принять призыв» и «Сбежать в замок»;
- праздничная анимация после принятия;
- атмосферный звук через Web Audio API;
- адаптация под телефон.

Сайт находится в `crossinvite/index.html` и не требует сборщика или сторонних JS-библиотек.
